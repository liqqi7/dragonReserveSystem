## 已确认的范围

- 一期包含手动资料、BGG 查询和收藏导入、每盒库存、本体与扩展、活动提名与计划、对局记录、榜单及统计表，以及 BGG 历史对局导入。BG Stats 按一期文件导入路径设计，已用真实 JSON 核验匿名多人、嵌套扩展和计分表结构；团队/合作、其他版本和图片本体仍需单独验收。
- BGG 可选。liqqi 的收藏仅是导入来源之一；不完整的收藏、未登记 BGG 的游戏、其他成员或外部持有者的实物都能录入。
- 保存本期请求的 BGG 接口实际返回的全部字段。分类、机制等保留原始 ID、英文名称及关系属性，一期不做中英文映射、标签展示或分类机制筛选。
- 同款多盒共用游戏资料、分别管理归属和状态；库存本身用一张表。游戏资料、活动和对局需要各自的表，不能把所有业务塞进一张库存表。
- 一场活动允许多款游戏；每个计划条目和每次实际对局选择自己的扩展子集，本体和扩展可以来自不同人的实物。
- 活动创建者和已报名成员都能提名；活动开始前可修改，不提前锁定。“最想开”将各活动的提名人数累加，跨活动不去重；“最想开”“开的最多”均有全体与我的视图。
- 榜单支持活动与月份、季度、年度、自定义时间范围组合筛选。已打卡的活动参与者都可记录本活动对局，实际玩家单独选择；对局数据在小程序内公开，胜率榜有 1 局有效结果即可进入。
- 一期导入历史对局并保留原始信息；历史导入数据是否展示、是否纳入榜单由用户后续决定，当前设计保持 held，不因导入成功自动发布。
- 拍照识别、AI/OCR、翻译、Codex CLI 方案、中英文映射和标签展示明确留到二期；当前图片URL及占位可用，照片上传尚未实现。

## 已确认的业务决策

以下已按用户本轮回复生效，替代 v1 的建议。未被本轮修改的常规完整性规则沿用原设计；不会把同一活动内的重复点击计成多个人。

| 编号 | 业务规则 | 已确定的口径 | 对设计的影响 |
| --- | --- | --- | --- |
| D01 | 提名人数加场数，不去重 | 按每场活动人数累加：同一人提名 3 场计 3 人次；例如 A 场 3 人、B 场 2 人，合计 5 人次，并显示 2 场 | 主排名按人次，活动数另列；不额外把 5 人次与 2 场再相加成 7 分 |
| D02 | 多维筛选 | 支持活动 + 月份/季度/年度/自定义日期组合；未筛选仍默认全部 | 提名按活动日期，对局按实际日期；月/季/年是时间选择的不同粒度 |
| D03 | 开始前都可修改 | 有资格者直到活动开始前均可新增、修改、撤回提名 | 删除提前锁定入口；活动延期到未来时重新开放符合资格的提名 |
| D04 | 已打卡参与者可记录 | 本活动 checked_in_at 非空的参与者都能记录，包括代记本活动其他桌；创建者/管理员保留原管理能力 | 仅报名未打卡不获得普通记录权限；不要求记录者必须出现在该局实际玩家中 |
| D05 | 按建议 | 成员补录缺失资料、管理自己的库存；共享资料、俱乐部/外部库存由管理员维护 | 保持原权限设计 |
| D06 | 小程序范围内公开 | 已发布对局在小程序内可读，不设活动外“仅本人可见”模式 | 公开可读与有权编辑分别校验；导入 held 数据按 D08 暂不发布 |
| D07 | 一局即可上榜 | 同款同模式有 1 局有效结果即可进入胜率榜，显示样本数 | 取消 5 局门槛；未知结果仍不能伪造胜率；同分沿用游戏规则优先、可选并列胜出/平局 |
| D08 | 一期可以导入 | BGG 历史一期导入；同时纳入 BG Stats 文件导入设计。展示不展示后续再定 | 保存来源、做玩家/游戏映射和重复处理；导入先 held，不自动进入普通列表、我的榜或全体榜 |
| D09 | 自助导入 | 成员导入本人，管理员可代导 | 原件限任务发起人访问 |
| D10 | 双来源先开发 | 同时支持 BGG/BG Stats；真实数据后续导入 | 本轮只用虚构/公开测试样例 |
| D11 | 真实页面及原型 | 按后续明确要求实现小程序页面并接API，同时补齐缺失原型 | 编译/自动化联调与真机验收分开记录 |
| D12 | 签到范围 | 不修改原有签到时点 | 仅接入关联资格锁 |
| D13 | 个性化成绩 | 摆烂算未获胜、入胜率分母、分数空 | 其他特殊状态和整局未完成分别处理 |
| D14 | 小程序用户 | 日常录局以小程序用户为主 | 导入玩家保留来源，正式导入时逐个匹配 |

后续补充E01–E16已经授权，本轮均按[3.2范围](design/boardgame-library/11-expanded-scope.md)推进。历史开放已有受控发布能力，实际用户数据何时公开在正式导入时再决定；开发不自动公开。

## 本轮交付边界

本轮在本地编写后端接口、数据库迁移及测试，同步页面流程设计；未导入真实业务数据、未连接生产、未提交或推送。`AGENTS.md` 原有修改保留。实际检查结果和部署边界见实施记录，原生小程序真机渲染未验收。
