## 关键业务证据

- 0分、负分、小数、未填和特殊状态分别保存；摆烂计已知未获胜并保留参局。整局abandoned排除完成局和结果分母。
- 分数/赢家/名次/团队/合作按主体一致校验；观察者与automa不进入人类榜。记分表原子变更及模板版本保留旧局，算式不会执行任意代码。
- 活动开始前提名、冻结/延期、退出与角色/签到撤销、删除活动历史快照、非参局记录人不计个人次数均有回归。
- 公开/held/草稿权限、不同发起人的任务/原件/映射、受控发布和映射变更令牌冲突有回归；同一份历史在重复任务中仍可核对与报告。
- UUID跨文件复用、RefId重排、缺UUID隔离、来源内容变化更新、quantity逐局确认、复制实物数量、mock BGG退避和原件保存有回归。
- 日期、活动、用户、环境、地点、扩展、角色、先手/初玩和计分主体口径检查；共享分数不按队员重复作数值样本，连胜不先排除输局。
- 原生10页控制器通过本机HTTP桥接访问临时后端，检验真实保存与回读、计分纸预览/应用、统计、提名、标签、私有核对和离线空态。

## 复现

所有命令从项目根执行（pytest一项注明backend）。不得复用生产DATABASE_URL。

```sh
cd backend
env DATABASE_URL=sqlite:// MEDIA_ROOT=/tmp/dragon-boardgame-test-media JWT_SECRET_KEY=synthetic-local-test-key BGG_API_TOKEN='' WECHAT_APP_ID='' WECHAT_APP_SECRET='' USER_INVITE_CODE=dragon ADMIN_INVITE_CODE=manage .venv/bin/python -m pytest tests -q --tb=short --show-capture=no
```

```sh
node --test miniprogram/tests/*.test.js
python3 backend/scripts/verify_boardgame_mysql.py --mysqld /opt/homebrew/opt/mysql/bin/mysqld --mysql /opt/homebrew/bin/mysql
python3 backend/design/boardgame-library/verify_mysql_schema.py --mysqld /opt/homebrew/opt/mysql/bin/mysqld --mysql /opt/homebrew/bin/mysql
python3 backend/design/boardgame-library/verify_design.py
python3 prototype/boardgame-library/build_prototype.py
```

MySQL脚本使用--no-defaults、临时datadir、独立Unix socket、skip-networking，结束时停止实例并移除临时数据。绝对可执行路径需按本机安装修改；脚本不会读取项目生产连接。
