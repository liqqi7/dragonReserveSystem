# BGG 专用代理

设置 `BGG_HTTP_PROXY=http://127.0.0.1:18973`，API 和桌游预览 worker 必须使用同一配置。覆盖名称搜索、Thing 详情（评分、排名、重度、版本）及 Geekdo 实体图片查询；不改变微信、天气、高德等其他请求。不自动回退直连，避免代理故障后重复等待或再次被拦截。保留 HTTPS 证书校验，不读取全局代理环境变量。图片 URL 仍由小程序直接加载，图片域名的微信配置需要单独验证。

节点配置仅保存在服务器私有文件中，勿提交凭据。代理监听回环地址，通过独立 `dragonreserve-bgg-proxy.service` 监管。先启动代理，再启动 API 与 worker。停止代理不会改变其他服务流量；BGG 查询按现有错误处理返回不可用。回滚应用配置时将 `BGG_HTTP_PROXY` 清空并重启 API 与 worker，之后可停止代理服务。

2026-10-09 腾讯云暂存版本实测：搜索 HTTP 200、2 条结果（0.61 秒）；Thing HTTP 200（0.64 秒），伯明翰评分 8.55901、重度 3.8602、38 个版本；图库 12 张（0.63 秒）。真实请求验证没有写入业务数据。
