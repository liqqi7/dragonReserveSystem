- 可读日志覆盖 **2026-08-10T12:50:01+08:00 至 2026-10-10T21:05:45+08:00**，解析 **97,722 条**完成请求，解析失败 **0 条**；只有 1 个 application.log，没有轮转文件。近 30 天跨越的 31 个自然日期均有记录。
- 下表次数是 HTTP 请求数，包含成功与失败。成功单独按 2xx 统计；204、201、202 均属于成功，202 仅表示任务被接受。图片资源的 304 单列为缓存命中，不作为故障。
- 请求数不等于使用人数、主动点击次数或业务成功次数。自动预取、轮询、重试、健康检查、图片加载都会产生请求；一次诊断请求可以包含多条事件。错误响应仍然证明接口被请求过，但不证明功能操作成功。
- 日志仅覆盖到达这个应用且写入完成记录的请求。代理直接拦截、客户端本地缓存、进程异常或未完成请求不在统计范围；不据此保证接口在所有环境永久无用。
- 以“HTTP 方法 + 路由模板”统计，忽略查询参数，把不同活动、桌游、库存、预览 ID 聚合到同一接口；先匹配静态路径，防止 recent-arrivals、mine 等被当成 ID。相同路径不同方法分别列出。
- 接口清单用本地和线上实际 OpenAPI 与已挂载路由的 AST 清单交叉验证。位置默认是当前本地代码；标注“线上”的位置来自服务器现有代码，不能用当前本地行号代替。
- 调用位置中省略目录前缀的 `pages/`、`services/`、`utils/` 均相对于 `miniprogram/`。本清单针对本项目提供的 HTTP 接口；微信、高德、和风、BGG 等上游服务及后端定时任务内部函数不作为本项目待删除接口统计。
