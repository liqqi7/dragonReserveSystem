## 后续新增素材归档规则

- 自 2026-09-22 起，用户新增的活动封面按**分类**归档，不再按画师或人名创建目录。
- 新文件统一放入 `backend/app/assets/activity-covers/categories/<分类>/`；封面 ID 仍保持稳定，分类以 `categories` 字段为准。
- 用户随图片提供的人名/署名必须写入封面的 `credit_name` 元数据；工作台会展示并支持按封面 ID、署名和历史作者查找。`credit_name` 不作为目录层级或分类依据。
- 此规则只适用于后续新增素材；既有按画师目录保存的历史封面不做迁移，避免改变已发布资源路径。
