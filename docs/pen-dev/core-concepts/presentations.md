# Slides and presentations

In the desktop app, use frames as slides to present a design or export a PDF.
Open **Slides** in the left sidebar to see the document’s visible top-level frames.

## Arrange slides[#arrange-slides](#arrange-slides)

Create a frame for each slide with the **Frame** tool (`F`). Nested frames stay
inside their parent slide. Drag thumbnails in **Slides** to change their order.

## Present[#present](#present)

Select a slide and click **Present**, or press `Cmd/Ctrl + Enter`.

- Use the arrow buttons or arrow keys to move between slides
- Press `Space` or `Enter` to advance
- Press `Esc` to return to editing

## Export a PDF[#export-a-pdf](#export-a-pdf)

In **Slides**, open **Export PDF** and choose **Export all slides** or
**Export selected slides**. The PDF follows the slide order, with one frame
per page. Each page uses its frame’s dimensions.
