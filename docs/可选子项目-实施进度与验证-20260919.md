## 本轮原型对齐规则（2026-09-19）
- 可选子项目展开态必须以 Pencil 原型节点 `zDxJM`、`gag4D`、`Htbju`、`X1H1ZT` 为几何基准；不能只凭通用 CSS 经验近似。
- “添加项目”必须保留原型的 `16px` 圆角和真实虚线边框路径；禁止用没有圆角保证的普通 CSS 虚线替代原型边框。当前实现使用 `miniprogram/images/activity-subitem-add-border.svg`，该 SVG 路径从原型节点 `RuzjT` 导出。
- 页面底部操作区必须保持透明，不能用白色不透明 footer 遮挡最后一个子项目或添加项目；内容不足时仍需保证最多四个子项目完整可见。
- Skyline 页面遇到“底部截断”问题时，先排查父容器的 `overflow`、flex 可用高度和 footer 覆盖关系；不得用遮挡、裁切或叠加补丁掩盖问题。
