- `miniprogram/pages/boardgame_library/`：自定义导航与状态栏适配、42px 搜索框、近期馆藏封面堆叠/详情 swiper 联动、当前项计数、双列封面卡、SVG 图标、灰色机制标签、橙色悬浮录入按钮。长标签和窄屏参数自适应换行。搜索请求过期响应不能覆盖新结果。
