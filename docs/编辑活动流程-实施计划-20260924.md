# 编辑活动流程：原型对齐与实施计划

日期：2026-09-24
状态：需求约束已确认，尚未开始业务代码实现。

## 1. 需求结论

本功能是一个独立的单页“编辑活动”流程，不把现有三步式“创建活动”向导改造成编辑页。实施时新增 `miniprogram/pages/activity_edit/`，保留 `activity_create` 的创建流程不变。

原型来源为：`prototype/龙城小程序.pen`。

本次重点节点：

- `l8JPT0`：编辑活动主页面
- `WTdTo`、`VG9sB`：封面选择抽屉的未选择/已选择状态
- `F2KEFX`、`mzb3Z`：开始时间/结束时间选择器
- `i0BOQg`、`UHfn0`、`YKzDp`：竖图、横图适宽、横图放大预览
- `ILtIN`、`w8KoUh`：画布分区标识，不作为运行页面实现

## 2. 不可降低的视觉实现约束

### 2.1 圆形 SVG 是强制要求

原型中呈现为圆形的图标、按钮、选择标记、预览控制和状态元素，必须使用圆形 SVG 实现。不得使用以下方式替代：

- CSS `border-radius` 加文字或 Unicode 符号
- emoji、字体图标或临时字符
- PNG/JPG 位图
- 用普通矩形图标通过裁切伪装成圆形

SVG 必须保留独立的 `viewBox`，并按照原型匹配圆形直径、描边宽度、填充色、透明度、图标位置和点击区域。需要新图标时，优先在项目已有 SVG 目录中复用；没有匹配资产时新增 SVG 文件，不临时用字符或 CSS 代替。

### 2.2 必须按原型逐项实现

原型节点是验收基准，不接受“功能相同但自行设计”的近似版本。实现和验收必须逐项对照：

- 页面结构、字段顺序和交互层级
- 390 设计宽度下的尺寸、间距、圆角和定位
- 颜色、字体层级、描边、阴影和遮罩透明度
- 抽屉、选择器、预览页的层级关系和返回路径
- 封面横向浏览、选中状态、预览缩放和设为封面流程
- 底部操作栏和安全区的实际占位
- 小屏、键盘、滚动和图片加载失败时的裁切与溢出

禁止为了“看起来差不多”增加原型没有的副标题、关闭叉、按钮、遮挡层或其他装饰。

## 3. 目标运行流程

```text
活动详情
  -> 编辑活动
  -> 编辑活动单页
      -> 查看/更换封面
          -> 封面选择抽屉
          -> 封面全屏预览
          -> 设为活动封面
      -> 编辑名称、地点、备注
      -> 选择开始/结束时间
      -> 编辑人数上限
      -> 开关并编辑可选子项目
      -> 保存修改
  -> 返回活动详情并刷新
```

## 4. 实施阶段

### P0：基线与接口确认

- 检查当前 `git status`，保留已有未提交改动，不执行 reset、clean 或覆盖原型资源。
- 读取 `activityService.getActivity`、`activityService.updateActivity` 和现有 `buildEditForm`。
- 确认活动字段、已报名人数、子项目字段和取消活动接口。
- 确认“取消活动”是改变活动状态，还是放弃本次编辑；未确认前不自行增加新的确认弹窗规范。
- 在修改 WXML/WXSS 前阅读对应 Skyline Skill。

### P1：编辑页骨架

新增：

```text
miniprogram/pages/activity_edit/activity_edit.js
miniprogram/pages/activity_edit/activity_edit.wxml
miniprogram/pages/activity_edit/activity_edit.wxss
miniprogram/pages/activity_edit/activity_edit.json
```

完成页面注册、详情页入口、活动数据加载、错误/加载状态、单页滚动区域、顶部导航、固定底部操作栏和安全区适配。

### P2：基础字段

实现活动名称、地点、备注、人数上限的回填与编辑，沿用现有字段转换和校验规则。保存前至少校验：必填字段、人数上限为正整数、人数上限不低于已报名人数。

### P3：封面选择和全屏预览

优先复用：

- `activity-cover-picker-sheet`
- `activity_cover_preview`

确保封面按作者/分类横向浏览，已选状态、预览入口、左右切换、适宽、放大、还原和“设为活动封面”都与原型一致。所有圆形预览控制和选择标记必须使用圆形 SVG。

### P4：日期时间和可选子项目

优先复用：

- `date-time-picker-sheet`
- `activity-subitems-editor`

实现开始/结束时间确认和校验，确保结束时间晚于开始时间；实现子项目回填、开关、编辑、增删改和已报名数据保护。

### P5：保存、取消和详情刷新

- 保存时锁定按钮，防止重复提交。
- 统一整理 `updateActivity` payload。
- 保存成功后发送 `activityUpdated`，返回详情页并刷新。
- 取消活动沿用已确认的业务接口和交互，不擅自改成放弃编辑。

## 5. 文件和组件边界

预计修改：

```text

```

仅在回传协议或原型展示确有差异时小范围修改封面选择器、日期时间选择器、子项目编辑器和预览页。不得为了编辑页重写创建流程，也不得覆盖当前工作区的无关修改。

## 6. 验收标准

### 自动化检查

- 新增编辑页逻辑测试，覆盖数据回填、字段修改、时间校验、容量校验、子项目修改、封面回传、保存 payload、重复提交和保存失败。
- 运行针对性测试后，再运行完整前端测试。
- 对修改后的 WXSS 执行：

```powershell
skyline-cli wxss check --miniprogram-root miniprogram --files <修改的 WXSS 文件> --json
```

- 执行 `git diff --check`。

### 原型和运行时检查

- 以 390 设计宽度截图逐节点核对位置、宽高、间距、颜色、圆角、阴影和层级。
- 检查整个编辑页、封面抽屉、两个时间选择器和三种封面预览状态。
- 检查圆形 SVG 的实际尺寸、描边和点击范围，确认没有 CSS/字符/位图替代品。
- 在微信开发者工具和真实 iOS/Android 设备分别验证滚动、输入、键盘、安全区、抽屉、预览手势和保存返回。
- 自动化检查通过不等于真实设备视觉验收通过。

## 7. 当前明确不做的事情

- 不修改现有创建活动三步向导的业务语义。
- 不把原型中的状态图当成额外页面。
- 不用 WebView 专有属性替代 Skyline 支持的组件属性。
- 不用遮挡、裁切、叠加补丁掩盖尺寸或层级问题。
- 未经视觉验收确认，不删除诊断日志、不提交版本、不扩大修改范围。
